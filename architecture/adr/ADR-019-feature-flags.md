# ADR-019 — Feature Flags

## Decision

All major features shall support runtime feature flags.

## Benefits

- Safe deployment
- A/B testing
- Gradual rollout
- Easy rollback

## Examples

- AI Director v2
- Experimental Models
- Beta Features

## Status

Accepted
