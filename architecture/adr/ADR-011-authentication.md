# ADR-011 — Authentication Strategy

## Context

AI Film OS requires secure authentication for individual users, teams, and enterprise organizations.

## Decision

Adopt JWT-based authentication with refresh tokens.

## Authentication Methods

- Email & Password
- Google OAuth
- GitHub OAuth
- Enterprise SSO (Future)

## Session Management

- Access Token
- Refresh Token
- Token Rotation

## Benefits

- Secure
- Scalable
- Mobile Friendly

## Status

Accepted
