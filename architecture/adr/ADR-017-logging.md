# ADR-017 — Centralized Logging

## Decision

All services shall use centralized structured logging.

## Log Categories

- Application
- AI
- Database
- Security
- API
- System

## Requirements

- Timestamp
- Request ID
- User ID
- Severity
- Service Name

## Status

Accepted
