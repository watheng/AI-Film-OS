# AI Film OS

# Search Engine

---

# Purpose

The Search Engine provides fast retrieval of production knowledge, assets, prompts, and project information.

It supports both keyword search and semantic AI search.

---

# Search Types

## Keyword Search

Search by

- Name
- Title
- Tag
- Metadata

---

## Semantic Search

Search by meaning.

Powered by Vector Database.

---

## Similarity Search

Find

- Similar Characters
- Similar Prompts
- Similar Images
- Similar Scenes

---

## Global Search

Search across

- Projects
- Assets
- Stories
- Characters
- Workflow
- Marketing

---

# Search Workflow

```
User Query

↓

Search Service

↓

Keyword Index

+

Vector Search

↓

Ranking

↓

Results
```

---

# Search Ranking

Results ranked by

- Relevance
- Similarity
- Recency
- Project Priority
