# ADR-047 — Semantic Versioning

## Decision

Use Semantic Versioning.

## Format

MAJOR.MINOR.PATCH

Example

1.0.0

1.1.0

1.1.1

## Rules

MAJOR

Breaking Changes

MINOR

New Features

PATCH

Bug Fixes

## Status

Accepted
