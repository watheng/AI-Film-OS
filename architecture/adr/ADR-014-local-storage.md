# ADR-014 — Local Storage

## Decision

Use MinIO during local development.

## Reasons

- S3 Compatible
- Docker Friendly
- Free
- Fast Local Testing

## Production Migration

MinIO can be replaced without changing application code.

## Status

Accepted
