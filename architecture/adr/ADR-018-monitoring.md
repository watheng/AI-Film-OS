# ADR-018 — Monitoring Strategy

## Decision

Monitor all critical infrastructure and application services.

## Metrics

- CPU
- Memory
- Disk
- API Latency
- AI Latency
- Queue Size
- Database Health

## Goals

- Early detection
- Capacity planning
- Performance optimization

## Status

Accepted
