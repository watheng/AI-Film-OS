# ADR-010 — AI Orchestrator

## Decision

The AI Orchestrator is the central control plane of AI Film OS.

## Responsibilities

- Workflow Coordination
- Agent Scheduling
- Model Routing
- Context Distribution
- Memory Synchronization
- Error Recovery
- Quality Control

## Benefits

- Single control point
- Modular AI execution
- Scalable architecture
- Easier monitoring

## Status

Accepted
