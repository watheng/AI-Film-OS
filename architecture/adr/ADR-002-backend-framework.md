# ADR-002 — Choose NestJS as Backend Framework

## Context

AI Film OS requires a modular backend architecture supporting AI orchestration, REST APIs, background workers, and enterprise-scale services.

## Decision

Use **NestJS**.

## Alternatives

- Express
- Fastify
- Spring Boot
- Laravel

## Reasons

- Dependency Injection
- Modular Architecture
- Strong TypeScript support
- Excellent testing
- Enterprise-ready

## Consequences

Positive

- Clean Architecture
- Easy maintenance
- Highly scalable

Negative

- Additional abstraction layer

## Status

Accepted
