# ADR-023 — Prompt Engine

## Decision

Centralize prompt generation through a Prompt Engine.

## Responsibilities

- Prompt Templates
- Prompt Variables
- Prompt Versioning
- Optimization
- Validation

## Benefits

- Consistent prompting
- Easier maintenance
- Reusable prompt library

## Status

Accepted
