# AI Film OS

# Project Structure

---

# Purpose

This document defines the standard project structure used by AI Film OS.

Every production project must follow the same structure to ensure consistency, scalability, maintainability, and compatibility across all workflows.

---

# Objectives

The Project Structure provides:

- Standard project organization
- Clear separation of production assets
- Consistent workflow integration
- Efficient project management
- Reusable production resources

---

# Project Hierarchy

```
Workspace

└── Project

    ├── Project Information
    ├── Project Bible
    ├── Project Memory
    ├── Story
    ├── Characters
    ├── World
    ├── Locations
    ├── Storyboard
    ├── Shot List
    ├── Prompts
    ├── Assets
    ├── Render Jobs
    ├── Outputs
    ├── Marketing
    ├── Versions
    └── Archive
```

---

# Project Information

Contains:

- Project ID
- Project Name
- Description
- Genre
- Production Type
- Language
- Resolution
- Aspect Ratio
- Current Status

---

# Project Bible

Stores all permanent creative decisions.

Examples

- Story Bible
- Character Bible
- World Bible
- Camera Bible
- Lighting Bible
- Prompt Bible

---

# Project Memory

Stores temporary and historical production knowledge.

Examples

- AI Decisions
- Prompt History
- User Feedback
- Review Notes
- Production Logs

---

# Naming Convention

Every project should use a standardized naming format.

Example

```
Project Name

↓

Story

↓

Scene

↓

Shot

↓

Render

↓

Output
```
