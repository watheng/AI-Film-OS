# ADR-005 — Choose pgvector

## Decision

Use PostgreSQL + pgvector.

## Reasons

- Semantic Search
- AI Memory
- RAG
- Prompt Retrieval
- Lower operational complexity

## Alternatives

- Pinecone
- Weaviate
- Qdrant
- Milvus

## Status

Accepted
