# ADR-020 — Deployment Strategy

## Decision

AI Film OS shall support multiple deployment modes from a single codebase.

## Deployment Modes

- Local Developer
- Studio (LAN)
- Cloud
- Enterprise

## Requirements

- Docker Compose
- Environment-based Configuration
- Zero Code Changes Across Environments

## Benefits

- Consistent deployments
- Easier maintenance
- Lower operational cost

## Status

Accepted
