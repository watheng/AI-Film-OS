# ADR-043 — Commit Convention

## Decision

Adopt Conventional Commits.

## Types

feat:

fix:

docs:

refactor:

perf:

test:

build:

ci:

style:

chore:

## Example

feat: add AI Director module

docs: update API documentation

## Benefits

- Automatic changelog generation
- Semantic versioning support
- Better commit history
