# AI Film OS

# Project Bible

---

# Purpose

The Project Bible is the single source of truth for every production.

It stores all permanent creative decisions and production standards throughout the entire lifecycle of a project.

Every AI module must reference the Project Bible before making recommendations or generating assets.

---

# Objectives

The Project Bible exists to:

- Maintain production consistency
- Prevent character drift
- Preserve creative decisions
- Reduce repetitive prompting
- Support long-term projects
- Enable team collaboration

---

# Structure

Every project contains one Project Bible.

The Project Bible consists of the following sections.

---

# Story Bible

Stores:

- Story premise
- Genre
- Theme
- Tone
- Plot outline
- Story structure
- Timeline
- Ending
- Rules of the story world

---

# Character Bible

Stores:

- Character profiles
- Appearance
- Personality
- Biography
- Motivation
- Relationships
- Voice style
- Costume
- Facial references
- Character rules

---

# World Bible

Stores:

- World setting
- Geography
- History
- Culture
- Technology level
- Social structure
- Environmental rules

---

# Location Bible

Stores:

- Locations
- Interior
- Exterior
- Architecture
- Reference images
- Lighting conditions
- Environmental notes

---

# Camera Bible

Stores:

- Camera language
- Preferred lenses
- Camera movement
- Framing rules
- Aspect ratio
- Shot style
- Cinematic references

---

# Lighting Bible

Stores:

- Lighting style
- Time of day
- Color temperature
- Mood
- Practical lights
- Cinematic references

---

# Color Bible

Stores:

- Color palette
- LUT references
- Contrast
- Saturation
- Highlight style
- Shadow style

---

# Sound Bible

Stores:

- Music direction
- Ambient sound
- Sound effects
- Voice style
- Audio references

---

# Prompt Bible

Stores:

- Master prompts
- Prompt templates
- Negative prompts
- Prompt variables
- Rendering presets

---

# Marketing Bible

Stores:

- Audience
- Platform strategy
- Campaign concept
- Thumbnail style
- Poster style
- SEO keywords
- Social media plan

---

# Asset References

Stores links to reusable assets.

Examples

- Characters
- Props
- Vehicles
- Buildings
- Environment
- Logos
- Music
- Sound

---

# Version History

Every important production decision should be recorded.

Examples

- Story revisions
- Character updates
- Prompt improvements
- Visual changes
- Production milestones

---

# Rules

Every AI module must read the Project Bible before:

- Story generation
- Storyboard creation
- Prompt generation
- Image generation
- Video generation
- Marketing generation

No module may overwrite approved Bible data without user approval.

---

# Benefits

Using the Project Bible enables:

- Character consistency
- Visual consistency
- Faster production
- Better collaboration
- Reusable creative assets
- Higher production quality

# Future Expansion

Future versions may include:

- Automatic Bible generation
