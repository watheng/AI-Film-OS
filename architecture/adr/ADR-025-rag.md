# ADR-025 — Retrieval-Augmented Generation

## Decision

Use Retrieval-Augmented Generation (RAG) for knowledge retrieval.

## Knowledge Sources

- Internal Knowledge Base
- User Projects
- Templates
- Prompt Library
- Character Profiles

## Benefits

- Higher factual accuracy
- Better personalization
- Reduced hallucination

## Status

Accepted
