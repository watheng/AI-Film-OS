# ADR-006 — Queue System

## Decision

Use Redis + BullMQ.

## Responsibilities

- AI Tasks
- Render Queue
- Background Jobs
- Notifications
- Retry Jobs

## Alternatives

- RabbitMQ
- Kafka
- Amazon SQS

Accepted
