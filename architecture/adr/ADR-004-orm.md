# ADR-004 — Choose Prisma ORM

## Decision

Use Prisma ORM.

## Reasons

- Type Safety
- Excellent Developer Experience
- Migration System
- Schema-first development
- Auto-generated client

## Alternatives

- TypeORM
- Sequelize
- Drizzle ORM

## Status

Accepted
