# ADR-015 — Cloud Storage

## Decision

Production deployments shall use S3-compatible cloud storage.

## Supported Providers

- AWS S3
- Cloudflare R2
- Backblaze B2
- MinIO Enterprise

## Selection Criteria

- Cost
- Availability
- Performance
- Vendor Neutrality

## Status

Accepted
