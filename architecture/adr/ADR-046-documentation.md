# ADR-046 — Documentation Standards

## Decision

Documentation is treated as production code.

## Requirements

- Version controlled
- Peer reviewed
- Updated together with code
- Written in Markdown

## Minimum Documents

- README
- API Documentation
- Architecture
- ADR
- User Guide

## Status

Accepted
