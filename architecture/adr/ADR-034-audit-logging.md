# ADR-034 — Audit Logging

## Decision

Record all critical system events.

## Events

- Login
- Logout
- Project Creation
- AI Execution
- Prompt Changes
- User Management
- Configuration Changes

## Goals

- Traceability
- Compliance
- Debugging

## Status

Accepted
