# ADR-007 — Multi-Agent Architecture

## Decision

Use specialized AI agents coordinated by an AI Orchestrator.

## Agents

- Director
- Writer
- Storyboard
- Cinematographer
- Editor
- Reviewer
- Marketing

## Benefits

- Separation of concerns
- Better scalability
- Independent specialization

Accepted
