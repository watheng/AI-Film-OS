# ADR-044 — Code Review

## Decision

All production code must be reviewed before merging.

## Review Checklist

- Architecture
- Code Quality
- Security
- Performance
- Testing
- Documentation

## Rules

No self-approval.

High-risk changes require two reviewers.

Accepted
