# ADR-033 — Rate Limiting

## Decision

Apply rate limiting to all public APIs.

## Goals

- Prevent abuse
- Prevent brute-force attacks
- Protect AI API budgets

## Default Limits

- Anonymous Users
- Authenticated Users
- Internal Services

## Status

Accepted
