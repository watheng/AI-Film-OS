# ADR-042 — Branch Naming Strategy

## Decision

Use standardized branch naming conventions.

## Naming

feature/project-dashboard

feature/ai-director

bugfix/login-error

hotfix/api-timeout

release/v1.0.0

## Benefits

- Easy identification
- Better automation
- Cleaner repository

Accepted
