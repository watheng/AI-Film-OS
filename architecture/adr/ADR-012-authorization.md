# ADR-012 — Authorization Strategy

## Context

Different users require different permissions across projects and workspaces.

## Decision

Implement Role-Based Access Control (RBAC).

## Roles

- Owner
- Administrator
- Producer
- Director
- Editor
- Viewer

## Permissions

- Read
- Create
- Update
- Delete
- Approve
- Publish

## Benefits

- Fine-grained access control
- Enterprise ready
- Easier auditing

## Status

Accepted
