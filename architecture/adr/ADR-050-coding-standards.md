# ADR-050 — Coding Standards

## Decision

Adopt a unified coding standard across the platform.

## Principles

- Readability First
- Simplicity
- Consistency
- Type Safety
- Testability
- Security by Default

## Requirements

- ESLint
- Prettier
- TypeScript Strict Mode
- Automated Formatting

## Status

Accepted
