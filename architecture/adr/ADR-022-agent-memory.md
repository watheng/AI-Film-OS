# ADR-022 — Shared Agent Memory

## Decision

All AI agents shall access a shared memory layer.

## Memory Types

- Session Memory
- Project Memory
- Character Memory
- Story Memory
- Long-Term Knowledge

## Benefits

- Consistent outputs
- Better collaboration
- Reduced duplicated work

## Status

Accepted
