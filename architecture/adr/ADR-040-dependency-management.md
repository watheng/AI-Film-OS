# ADR-040 — Dependency Management

## Decision

Dependencies shall be managed centrally and updated regularly.

## Rules

- Prefer stable releases
- Review licenses
- Minimize unnecessary packages
- Regular security updates

## Goals

- Security
- Stability
- Maintainability

Accepted
